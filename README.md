# MFC25Ent_densuke

松丘FC 出欠管理アプリ（`index.html` 単体で動作）。伝助の置き換え。

名簿・PIN・出欠はこのリポジトリには含めません。アプリの中（端末内 + Firestore）だけに持ちます。

## Firebase（Firestore）連携

複数端末でデータを共有するため、Firestore にリアルタイム同期します。
`index.html` 末尾の `FIREBASE_CONFIG` が空のあいだは、従来どおり端末内（localStorage）だけで動作します。

### セットアップ
1. [Firebaseコンソール](https://console.firebase.google.com/) でプロジェクトを作成
2. **Authentication → ログイン方法 → 「匿名」を有効化**（これが無いとクラウド同期しません）
3. 「Firestore Database」を作成（本番モード・リージョンは `asia-northeast1` 推奨）
4. 「ルール」に `firestore.rules` の内容を貼り付けて公開
5. 「プロジェクトの設定 > マイアプリ」で Web アプリを追加し、表示された設定値を `index.html` の `FIREBASE_CONFIG` に貼り付け
6. （推奨）**App Check → reCAPTCHA v3** でサイトキーを発行し、`RECAPTCHA_SITE_KEY` に貼り付け
7. **管理者の端末で最初に開く** → クラウドが空なら、その端末のデータが初期データとして登録されます
8. 以降、他の端末はクラウドのデータを読み込みます

### 名簿の登録
初回は名簿が空です。管理者でログインし、「管理」タブの
**データの書き出し・読み込み → 読み込む（JSON）** から名簿ファイルを読み込みます。
このファイルは個人情報なのでリポジトリには置きません（`*.local.json` は `.gitignore` 済み）。

### PINコード
事前に配りません。**各自がはじめてログインするときに自分で4桁を決めます。**
PINを配り直したいときは、管理画面の「全員のPINを未設定に戻す」を使います。

### バックアップ
管理画面の「書き出す（JSON）」で全データをファイルに保存できます。
ブラウザの保存領域は消えることがあるため（Safariは未使用7日で消去）、ときどき書き出しておくと安全です。

### データ構造
| パス | 内容 |
|---|---|
| `team/meta` | アプリ名・入力期限日数・Googleカレンダー設定 |
| `team/logo` | ロゴ画像（base64） |
| `team/users` / `team/members` / `team/events` | ログイン情報 / 選手・コーチ / 予定 |
| `att/{eventId}` | 予定ごとの出欠。フィールド名が member id（本人の分だけ書くので同時入力でも上書きしません） |

### 注意（セキュリティ）
- 読み書きできるのは匿名ログインを通った端末だけです。ただし**アプリのURLを知っていれば誰でも匿名ログインできる**ため、URLをチーム外に共有しないでください。
- PINの照合はブラウザ側で行っています。厳密に守る必要が出たら、保護者ごとのログイン（Firebase Auth）への移行が必要です。
- 初回同期が終わるまでは書き込みません（古い端末のデータでクラウドを上書きしないため）。
- 匿名ログインに失敗した場合はクラウドを使わず、端末内だけで動作します。
